# Themes to bundle, by their name in iTerm2-Color-Schemes' ghostty/ directory.
# One per line. Formats:
#   Name                      slug is the lower-cased name with dashes
#   Name => slug              choose the slug
#   Name | SPDX | source-url  licence override, for a scheme licenses.yml
#                             lists as unknown but whose licence was checked
#                             at source-url
# The importer refuses any scheme whose licence is not on its allow list.
# Gruvbox Dark, Catppuccin Mocha and TokyoNight Night are not listed because
# Ultty already ships hand-tuned `gruvbox-dark`, `catppuccin-mocha` and
# `tokyo-night`.
