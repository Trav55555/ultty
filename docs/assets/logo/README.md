# Ultty logo

The mark is `->>>_`: a pine tree laid on its side, its trunk the dash and its
three tiers the chevrons, with a cursor at the end. Colours
are Ultty's default Everforest palette: aqua `#83c092` chevrons, green
`#a7c080` dash and cursor, `#d3c6aa` wordmark on dark and `#2d353b` on light.

| File | Use |
|------|-----|
| `ultty-mark.svg` | The `->>>_` mark alone |
| `ultty-logo-dark.svg`, `ultty-logo-light.svg` | `->>> ultty_` lockup for dark and light backgrounds |
| `ultty-animated-dark.svg`, `ultty-animated-light.svg` | The README header: `->>>_` blinks, then `ultty` types out (SVG SMIL, plays once, then the cursor blinks) |
| `ultty-tree-dark.svg`, `ultty-tree-light.svg` | Upright pine tree with `ultty_` |

The app icon in `dist/icons/hicolor/` is the same sideways tree, trunk and
three equal chevrons, on a dark rounded tile.
