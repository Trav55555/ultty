# Ultty Brand Assets

The Ultty logo and app icon are original project assets and follow the repository license.

## Files

- `dist/icons/hicolor/scalable/apps/ultty.svg`: editable source and scalable Linux desktop icon.
- `dist/icons/hicolor/32x32/apps/ultty.png`: small launcher/icon-list export.
- `dist/icons/hicolor/64x64/apps/ultty.png`: standard launcher export.
- `dist/icons/hicolor/128x128/apps/ultty.png`: high-density launcher export.
- `dist/icons/hicolor/256x256/apps/ultty.png`: release-page and high-density export.

## Usage

Use the icon on dark or light backgrounds with enough clear space for the rounded outer shape to remain visible. At small sizes, prefer the square app icon over placing the wordmark beside it.

Minimum practical sizes:

- App icon: 32px.
- Documentation or release artwork: 128px.

The desktop entry uses `Icon=ultty`, and Linux `.deb`, `.rpm`, and Homebrew installs place the icon in the hicolor theme so desktop environments can resolve it by name.
