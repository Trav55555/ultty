# Compatibility scorecard

What Ultty does for terminal features that modern programs, agent CLIs
especially, rely on. Generated by `scripts/compat-scorecard.sh` from the
`scorecard_` tests: a row says "Yes" only while its test passes. The checks
are in [`crates/ultty-vt/tests/scorecard.rs`](../crates/ultty-vt/tests/scorecard.rs)
and, for key encoding, `crates/ultty/src/keys.rs`. The README's
[ANSI Compatibility](../README.md#ansi-compatibility) section lists the rest.

| Feature | Ultty | What programs use it for | Notes |
|---|---|---|---|
| Synchronized output (mode 2026) | Yes | Redrawing a whole screen without flicker: agent CLIs, editors | DECRQM reports it |
| Kitty keyboard protocol | Yes | Shift+Enter for a new line in agent prompts; keys legacy encoding cannot tell apart | Flags 1, 2, 4, 8 and 16; query, push, pop |
| Bracketed paste (mode 2004) | Yes | Pasting a multi-line prompt without running it | ESC and C1 controls are removed from pasted text |
| Focus reporting (mode 1004) | Yes | Pausing or redrawing when the window loses focus |  |
| Alternate screen (mode 1049) | Yes | Full-screen programs that restore the shell on exit |  |
| SGR mouse (mode 1006) | Yes | Clicks and scrolling in TUIs, at any column | Also X10, 1005, 1015, 1007 |
| Grapheme clustering (mode 2027) | Yes | Emoji and combining text that line up with what the program expects |  |
| 24-bit colour, underline styles and colour | Yes | Syntax highlighting, diagnostics squiggles | SGR 4:x, 58, 59 |
| Hyperlinks (OSC 8) | Yes | Clickable file paths and URLs in output | Ctrl+click opens http, https, mailto and ftp only |
| Clipboard writes (OSC 52) | Yes | Copying from a program, including over ssh | Reads are refused; writes can be turned off |
| Shell prompt marks (OSC 133) | Yes | Knowing where commands and their output start and end | Feeds `ulttyctl last-command` and command events |
| Working directory (OSC 7) | Yes | Opening a new tab where the shell is |  |
| Desktop notifications (OSC 9, OSC 777) | Yes | "Done" or "needs input" from a long-running agent |  |
| Progress (OSC 9;4) | Yes | A progress bar on the tab; ConEmu's sequence, also read by Windows Terminal and Ghostty |  |
| Theme change reports (mode 2031) | No | Programs restyling when the system switches light/dark |  |
| Colour queries (OSC 10, 11) | Yes | Choosing a light or dark palette at start | Reports the live theme |
| Terminal name (XTVERSION) | Yes | Detecting the terminal without guessing from TERM |  |
| Sixel images | Yes | Inline images and plots |  |
| Kitty graphics protocol | No | Inline images in programs that only speak kitty's protocol | Use Sixel |
