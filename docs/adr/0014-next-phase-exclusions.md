# ADR 0014: Next-Phase Exclusions

The next phase excludes desktop-style GUI embedding, arbitrary canvas or drawing APIs in the native protocol, collaborative rich-document editing, Windows runtime support, broad widget breadth not needed for the agent/workshop console, and visual effects that compromise terminal correctness, idle efficiency, or dual-mode behavior. These are not rejected forever; they are deferred so the project can deepen the terminal, native runtime, observability, streaming, and dual-mode framework foundations first.
