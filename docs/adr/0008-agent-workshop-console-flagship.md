# ADR 0008: Agent/Workshop Console as Flagship Scenario

Ultty's flagship native app scenario is an agent/workshop console. This workload exercises the native runtime's strongest reasons to exist: append-oriented markdown streams, structured status, panes, command palettes, keyboard-first workflows, long logs, tables, forms, focus, and runtime observability, while avoiding demos that are too small or too desktop-GUI-shaped to prove terminal-native value.
