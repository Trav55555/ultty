## Known limitations for this candidate

- Ultty is Unix-first. Linux and macOS are the supported runtime targets; Windows requires future ConPTY/native transport work.
- This is not a general-use release candidate.
- Public-alpha evidence is incomplete until hosted CI, security audit, release artifact smoke, install verification, and known-limitation release notes are tied to this candidate.
- Local GUI/live-smoke evidence exists, but a hosted/dedicated live-smoke workflow URL or an explicitly accepted local substitute is still needed before publication.
- Basic terminal workflow smoke passed locally, but a broader workflow matrix for full-screen editors, interactive pagers, resize-heavy TUIs, tabs, splits, copy mode, paste behavior, and richer job-control scenarios remains pending.
- Package install/upgrade/uninstall evidence is pending for advertised distribution channels.
