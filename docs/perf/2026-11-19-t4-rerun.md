# T4 rerun on `main`: memory, startup and control latency (2026-11-19)

Plan items D3, D4 and D6 each waited on a T4 measurement. This is the same
three-terminal campaign as [2026-11-11](2026-11-11-t4-three-way.md), on
current `main`, plus D6's control-latency script on the real X display.

## Environment

- AWS g4dn.xlarge (Tesla T4, NVIDIA 580.178.04, 4 vCPUs), us-east-1a, on
  demand, from the bench image `ultty-bench-gpu-2026-11-08`
  (`ami-0fe200d7ed965618f`), as on 2026-11-11.
- Ultty `e04885b72ce6` (`main` after #148, #149, #165), release build on
  the instance. Ghostty 1.4.0, Alacritty 0.16.1, sway 1.11.
- X11: headless Xorg on the GPU with openbox. Wayland: private headless sway,
  `WLR_RENDERER=gles2`, 60 Hz. 120x40 cells, DejaVu Sans Mono 11. Three
  rounds, terminal order shuffled, 200 key presses per launch and case.
- One failed measurement: Ghostty's round-0 X11 throughput window never
  appeared, so Ghostty's X11 throughput, RSS and startup rows have n=6 or
  n=2 instead of 9 or 3.

fixed in #148 is not present.

## Control plane on a real display (D6)

`scripts/bench/control-latency.py --pid <ultty> -n 2000`, three rounds,
against Ultty on the T4's X display:

| Path | median | p99 | max |
|---|---:|---:|---:|
| request: connect, `ping` with the token, reply read to EOF | 0.10-0.12 ms | 0.16-0.18 ms | 0.19-0.46 ms |
| `ulttyctl ping`, process start to exit | 1.00-1.06 ms | 1.21-1.25 ms | 1.5-1.6 ms |
| event: `send_text` to a background `cat`, echoed OSC 9 back | 0.29-0.31 ms | 0.39-0.83 ms | 1.3-2.8 ms |
| event+draw: the same with an OSC 2 title, so each event draws | 0.29-0.32 ms | 0.95-1.23 ms | 1.0-1.5 ms |

Every path stays well under a frame on real hardware. The medians are about
twice the [Xvfb numbers](2026-11-08-control-latency.md) (a 4-vCPU cloud
instance against a desktop CPU); the event+draw p99 is no worse, so drawing
on a real GPU adds nothing to the control loop.

## What this says about the plan rows

- **D3 (RSS after the feed at or under Alacritty's on the T4): not met.**
  Ultty is 174 MiB on X11 against Alacritty's 114 MiB, the same as
  2026-11-11. The glyph atlas cut (D3's first slice) shows up in GPU memory,
  not in this RSS, which the NVIDIA driver dominates.
- **D4 (exec to titled window at or under Alacritty's on the T4): not met,
  improved.** 349 ms against 193 ms on X11, down from 400 ms. The remaining
  gap is the NVIDIA Vulkan instance, device and swapchain setup measured on
  2026-11-08 (~240 ms of the start).
- **D6 (control latency on a real display): met.** See above.

## Commands

```bash
# on the instance, after aws-remote.sh setup gpu and build of e04885b:
ARGS=(--terminals ultty,ghostty,alacritty --rounds 3 --k2p-samples 200
      --ultty-dir ~/ubench/target/release --bench-dir ~/ubench/target/release)
DISPLAY=:0 scripts/bench/compare.sh --session x11 --out .../x11 "${ARGS[@]}"
WLR_RENDERER=gles2 scripts/bench/compare.sh --session wayland --out .../wayland "${ARGS[@]}"
DISPLAY=:0 ~/ubench/target/release/ultty &   # private XDG_RUNTIME_DIR and config
scripts/bench/control-latency.py --pid $! -n 2000
```
