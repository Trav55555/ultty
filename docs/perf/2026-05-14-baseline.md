## Memory Detail

> **Invalid (2026-11-07).** These figures came from arithmetic, not
> measurement: the bench assumed 16-byte cells (they are 20) and fully
> allocated scrollback, and its PASS could not fail. Compact scrollback

> `Terminal::new`, not memory. The memory bench now counts heap bytes with a

## Caveats

- Idle CPU/GPU work is a runtime behavior target. The idle event-loop fix is
  validated by unit tests, but this artifact does not include an external
  process-level idle power or GPU activity measurement.
- Criterion reports local timing ranges and outliers. Re-run the commands above
  on target hardware before treating the numbers as release claims.
- The render benchmark uses Ultty's headless benchmark renderer path; it is
  useful for regression tracking, but it is not a substitute for end-to-end
  present-latency instrumentation.
